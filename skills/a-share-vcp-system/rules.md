# A股 VCP 交易体系 — 参数总表与决策依据

> 本文件是 `a-share-vcp-system` 技能的参考手册，由 2026-08-11「扩散收敛法」对话结晶提炼。完整手稿见 `交易体系构建-手稿.md`。

## 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| 持仓周期 | 2–8 周 | 日线级别信号，SEPA 原生节奏 |
| 市场过滤 | 板块 RS 最强 + 资金流入 | 无主线板块则不开新仓 |
| 选股 | 板块内 VCP 形态龙头 | 收缩幅度递减、量能萎缩、逼近枢轴 |
| 买点 | 放量突破枢轴（量能 ≥ 前5日均量 1.5 倍，收盘站上） | 涨停买不进→次日不追，等回踩 |
| 止损 | 跌破枢轴/平台下沿 或 浮亏 8%（20cm 股 12%），先触发为准 | 收盘价确认，不看盘中插针 |
| 止盈 | 收盘跌破 20 日线 或 放量滞涨加速离场 | 吃主升段中段 |
| 单笔风险 | 1.5–2%（激进档） | 连亏 3 笔后降档至 1% |
| 单笔仓位上限 | ≤25%（硬性截断） | 回测发现：止损距离过近时公式算出超大仓位（0.35% 止损→约 5.7 倍），一律按 25% 截断 |
| 最大持仓 | 5–6 只 | 单板块 ≤3 只 |
| 单日刹车 | 账户回撤 3% 停开新仓 | 防连错失控 |
| 加仓 | 仅盈利金字塔加仓 | 绝不补仓摊平 |
| 主线资格 | 20 日 RS 为正的板块才可标为主线 | 负 RS"主线"多为窗口噪声（2026-08-18 机器人板块 −2.2% 挂主线实证） |
| 全市场刹车 | 上证当日跌幅 >1.5% 停开一切新仓 | 系统性杀跌日不做买入（2026-08-19 全链 −5~−9% 实证） |
| 存量仓位纳管 | 非信号仓位发现当日补：技术止损+硬止损（成本×0.92/0.88）+仓位核查 | 广合科技教训：无止损持仓是体系最大漏洞 |
| 消息面三查 | 入场前查业绩兑现/公告排雷/催化阶段，任一不过关信号降级 | 把自发核查固化为强制流程 |

## 决策依据摘要（为何是这个体系）

1. **体系定位**：完整实战系统。用户有明确 SEPA/VCP 方向与实践意图，不需要停留在方法论研究。
2. **周期选中线波段**：A 股板块行情通常持续 1–3 个月，2–8 周持仓可吃主升段中段；无需全天盯盘；VCP 收缩形态在日线级别最典型。否决短线（T+1 隔夜风险、需盯盘）与中长线（15–20% 回撤考验）。
3. **市场过滤选行业相对强度**：SEPA 原生逻辑——只买相对大盘最强的板块。用户明确选择不做全局指数择时，接受"指数级下跌时仍会亏"的代价；指数趋势开关记入延后口子，二期决定是否叠加。
4. **选股选板块驱动**：A 股是板块市，主线板块内选股胜率显著更高，且与行业过滤同构。否决全市场扫描（脱节）、基本面双轮（A 股财务数据可比性差）、资金流驱动（数据真实性难验证）。
5. **买点选 VCP 突破**：平台突破信号明确、可复盘。A 股特有预案：突破当天可能涨停封死 → 次日不追高、等回踩。
6. **止损双保险**：技术位保形态逻辑，硬止损防黑天鹅（财报暴雷、系统性下杀）；收盘价确认防插针扫损。20cm 股波动大，硬止损放宽至 12%。
7. **止盈 20 日线跟踪**：让利润奔跑、吃主升段中段；放量滞涨作为加速离场条件，板块退潮时少亏几个点。
8. **资金管理激进档**：用户主动选择。风险数字：单笔 2%×止损 8% ≈ 仓位 25%，6 只满仓理论回撤 12%，连亏 3 笔 −6%。以承受 30%+ 回撤换取收益弹性。

## 延后口子（二期，占位不实现）

- 指数趋势开关：指数站上 200 日线且中期均线向上才允许开仓。
- 口袋支点买点：回调中放量上涨日低吸，VCP 突破前的抢先手。
- 基本面排雷清单：商誉、质押比例、减持计划等买入前排雷。
- 复盘自动化工具：交易记录、纪律打分、绩效统计自动化。

## 回测验证记录（2026-08-11）

纸面回测（近 320 交易日，5 只样本股，前复权日线）结果：

| 指标 | 数值 |
|------|------|
| 交易笔数 | 22 |
| 胜率 | 54.5% |
| 平均盈利 / 平均亏损 | +13.92% / −5.21% |
| 盈亏比 | 2.67 |
| 单笔期望 | +5.22% |

结论：8%/12% 硬止损与 20 日线止盈参数验证为合理（硬止损实为尾部保险，多数止损由技术位在 −1%~−7% 提前触发）。**暴露缺陷**：止损距离过近时仓位公式算出超大仓位（如比亚迪一笔止损距离 0.35%→约 5.7 倍仓位），已加单笔 25% 上限修正。局限：样本小（22 笔）、未启用板块过滤、未计成本；需扩大样本复核。

## 实盘复盘记录（2026-08-11 至 2026-08-19）

首周实运行验证结果：

- **验证有效**：锦浪信号全链路（板块RS+放量突破+追高线）正确触发，8-14 破枢轴按规则离场；1.5 倍量能闸门拦下航发动力/中航西飞/埃斯顿三次无量假突破；追高线正确拦截天孚（+7%）、光迅（+3.5%）等已突破标的。
- **暴露缺陷与对应补丁**：
  1. 广合科技（非信号仓位，成本 169.3）无预设止损，8-19 击穿硬止损于约 152 清仓（−10.2%）→ 新增**存量仓位纳管**规则。
  2. 板块 RS 排名日间剧烈摆动（消费一天 +9.2%→−8.6%；机器人 −2.2% 负 RS 挂主线）→ 新增**主线资格须 RS 为正**。
  3. 8-19 系统性杀跌日（旭创 −9.3%、新易盛 −8.8%）扫描照常输出候选 → 新增**全市场刹车**（上证跌 >1.5% 停开新仓）。
  4. 消息面核查（锦浪/广合）均为自发行为 → 固化为**入场前消息面三查**。
- **记录在案暂不修改**：回踩再入场规则（天孚案例样本不足）、候选状态→动作映射表。
