# A股 VCP 趋势交易体系（执行手册）

> 本技能是「交易体系构建」对话结晶后的**执行层手册**。完整决策依据与历史记录见同目录 [rules.md](rules.md)。参数调整需经复盘确认，不得随意改动。

## 体系总览

一句话：**只做 RS 最强板块里的 VCP 形态龙头，放量突破买，破位止损、破 20 日线走。**

完整链路：市场过滤（板块 RS）→ 选股（板块内 VCP 龙头）→ 买点（放量突破枢轴）→ 止损（技术位+硬性双保险）→ 止盈（20 日线跟踪）→ 资金管理（激进档）→ 每周复盘。

## 执行流程

### 每日开盘前（约 10 分钟）

1. **市场过滤**：查看板块 RS 排名（板块指数相对大盘的相对强度 + 资金流入），锁定当前主线板块。主线板块缺失或走弱时，当日不开新仓。
2. **选股扫描**：在主线板块内扫描 VCP 形态——波动连续收缩（每次收缩幅度递减）、量能萎缩至地量、价格逼近枢轴点。
3. **输出候选清单**：每只候选给出 股票代码 / 名称 / 枢轴价 / 止损价 / 建议仓位（= 单笔风险 ÷ 止损距离）。

### 买入执行

- **触发**：候选股放量突破枢轴点（当日量能 ≥ 前 5 日均量的 1.5 倍），收盘价站上枢轴。
- **涨停预案**：突破当天涨停封死买不进 → 次日高开**不追**，等待回踩企稳再介入。
- **开仓限制（硬性）**：最多同时持有 5–6 只；单板块 ≤3 只；当日账户回撤已达 3% 则停止开新仓。
- **仓位公式**：单笔仓位 = 单笔风险（1.5–2%）÷ 止损距离（%）。示例：风险 2%、止损距离 8% → 仓位 25%。
- **仓位上限（硬性）**：单笔仓位 ≤ 25%，超过一律按 25% 截断。止损距离过近时公式会算出超大仓位（回测实测：止损距离 0.35% 时算出约 5.7 倍仓位），紧止损本身说明入场点质量差，绝不允许用放大仓位去补偿。

### 持仓监控（每日收盘后）

- **止损**（先触发者为准，均用收盘价确认，不看盘中插针）：
  - 技术位：收盘跌破 VCP 枢轴/平台下沿 → 卖出；
  - 硬性：浮亏达 8%（创业板/科创板 20cm 个股放宽至 12%）→ 卖出。
- **止盈**：
  - 主规则：收盘跌破 20 日线 → 卖出；
  - 加速条件：放量滞涨（长上影、天量收阴）或板块退潮 → 提前离场。
- **加仓**：仅限浮盈后的金字塔加仓（越加越少），**绝不补仓摊平**。

### 每周复盘（周末，约 30 分钟）

1. 对照下方纪律清单逐条打分，找出违反项。
2. 检查候选池与板块排名是否有变化，更新下周主线板块。
3. **更新交易台账（强制）**：每笔交易必须当日落账，字段固定为 日期 / 代码 / 方向（买/卖）/ 价格 / 仓位% / 触发理由 / 退出原因 / 盈亏% / 持仓天数 / 纪律执行情况。台账是参数调整与降档判断的唯一依据，不补记、不漏记。
4. 连亏 3 笔 → 暂停开仓 1 周，下一周降档运行（单笔风险降至 1%）。

## 纪律清单（不可违反）

- 绝不向下摊平——止损价买错就认，加仓只发生在浮盈之后。
- 止损用收盘价确认，不做盘中插针式止损。
- 涨停买不进不追高，等回踩。
- 单日账户回撤 3% 停开新仓。
- 单笔仓位 ≤ 25%，紧止损不用放大仓位补偿。
- 每笔交易当日记入台账，不补记、不漏记。
- 不凭消息、不猜底、不预测，只跟随信号执行。
- 参数调整必须基于复盘记录，不盘中改规则。

## 数据源

板块与个股行情可用公开行情接口自行获取，例如腾讯行情：`curl https://qt.gtimg.cn/q=sh603986`（返回 GBK 编码，~ 分隔字段，含现价/涨跌幅/成交额等）。注意：WebFetch 抓雪球等页面常被防护脚本拦截，优先用行情接口。详见 [rules.md](rules.md) 的数据源与待核对事项。

## 参数总表

完整参数表、量化依据、被否决方案与延后口子见 [rules.md](rules.md)。MVP 阶段参数：止损 8%（20cm 12%）、止盈 20 日线、单笔风险 1.5–2%、单笔仓位上限 25%、最多 5–6 只、单板块 ≤3 只、单日回撤 3% 刹车。
