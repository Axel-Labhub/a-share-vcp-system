# A股 VCP 趋势交易体系（v1.5 · 当前平台适配版）

## 体系定位

一句话：**只做相对强度(RS)最强板块里的 VCP 形态龙头——放量突破买，破位止损、破 20 日线走。**

米内尔维尼 SEPA / VCP 趋势思想的 A 股本土化：中线波段（2–8 周）、板块驱动选股、技术位 + 硬性双保险止损、20 日线跟踪止盈。核心不是高胜率，而是「截断亏损、让利润奔跑」——多数小亏 + 少数大赚，靠正期望而非预测。

> 完整参数总表、决策依据、回测与实盘记录、数据源实测限制，见 `references/rules.md`。执行前若需精确数值，读它；日常对话用下面的速览即可。

### 实测关键限制（2026-08-21 至 08-23 验证，务必遵守）

1. **板块指数不可直查**：finance-data 查「XX板块涨跌幅」会误识别为个股（「机器人板块」→个股机器人 300024.SZ），查同花顺行业指数返回空。RS 必须走下方「两层 RS 方案」。接口明确**禁止重试 ≥2 次**，空结果即换路径。
2. **板块 ETF 行情也不可直查**：黄金ETF(518880)、半导体ETF(512480) 实测均返回空——行情接口数据库只覆盖 A 股个股。**代表股代理是板块强度的唯一可行路径**，不要再尝试任何板块指数/ETF 查询。
3. **指数行情滞后一个交易日**：上证指数逐日序列实测最新仅到前一收盘日。全市场刹车的当日涨跌幅改用 finance-news 市场简报或个股口径补齐，并在报告标注数据时点。
4. **结果文件要下载解析**：`get_result` 返回的 `result_json_path` 需下载到本地，用 `scripts/rs_calc.py`（板块RS）与 `scripts/vcp_calc.py`（个股VCP）做确定性计算。
5. 所有行情结论必须标注数据日期；盘中执行时，技术位计算以已收盘数据为准。

## 两层 RS 方案（板块指数不可直查的工程化替代）

**一线快筛（每次扫描必做，全部用 `scripts/rs_calc.py` 确定性计算，禁止手算）**：
- 对候选池每个板块，取 **4 只代表股**（不足 4 只的按现有数量，但报告中须标注「样本不足」降低置信度），用 finance-data 查每只「近 70 个交易日日K线」。
- 上证基准：查上证指数近 21 个交易日序列（注意滞后一天的限制），同样下载 JSON。
- 写一份 `rs_config.json`（benchmark + 各板块代码→文件映射），跑 `python scripts/rs_calc.py --config rs_config.json`。脚本输出：各股 20 日涨幅、**板块代理涨幅 = 代表股 20 日涨幅中位数**、**一致性**（20 日涨幅为正的代表股占比）、**5 日动量中位数**、代理 RS、确定性判定。
- **三条硬门槛（脚本自动判定，禁止人工覆盖）**：
  1. 一致性 < 50% → 降级（单股绑架，板块宽度不足）
  2. 代理 RS ≤ 0 → 降级（负 RS 主线多为窗口噪声）
  3. 5 日涨幅中位数 < −3% → 降级（动量背离 = 资金正在撤离）
- 三条全过 → **主线候选**；按代理 RS 降序排列。
- 设计动机：均值法会被单只妖股绑架（08-21 实测医药 +7.42% 全靠药明康德 +30.3%，恒瑞实为 −10.7%）；中位数抗异常，一致性验宽度（真主线是群体上涨），5 日动量把二线复核从主观解读变成可复现闸门。

**二线复核（仅对一线产生的主线候选，逐个做，不普调）**：
- 先 `finance-news` 板块涨跌报告核对近期资金面与催化性质；涉及开仓决策的板块再用 `finance-sector` 出板块研报。
- 二线的定性作用：**确认催化是否可持续**（政策/业绩/涨价等逻辑能否支撑 2–8 周）+ 排雷（板块级利空）。二线与一线判定矛盾时，在报告中并列呈现分歧，但**降级与否以一线硬门槛为准**（门槛已覆盖动量背离）。
- ⚠️ 已知失真风险：代表股近似板块强度仍可能失真（原体系实测光伏板块指数 +5.5% vs 代表股平均仅 +0.2%），所以一线候选必须经二线复核才能在报告中标注为「主线」。

## 命令 1：每日选股扫描

**目标**：输出「今日能否开新仓 + 主线板块 + VCP 候选清单」。没有主线时明确说「今日不开新仓」，不硬凑候选。

**流程**：

1. **全市场刹车**：用 finance-news 市场简报（或 finance-data 指数行情，注意滞后一天）取上证当日涨跌幅。跌 > 1.5% → 输出「系统性杀跌日，停开一切新仓」，结束。
2. **板块代理 RS 排名（一线）**：按「两层 RS 方案」一线快筛执行——每板块 4 只代表股查 70 日 K 线 + 上证指数序列，写 `rs_config.json` 后跑 `scripts/rs_calc.py`，输出含一致性/5日动量/硬门槛判定的完整排名表。
3. **主线判定 + 二线复核**：通过三条硬门槛的板块为主线候选；对候选逐个做二线复核。**若无板块通过硬门槛，输出「今日不开新仓」并结束**（负 RS 或单股绑架的「主线」均为噪声）。
4. **VCP 扫描**：对每个主线板块的候选池，用 finance-data 取每只股票近 70 个交易日 K 线，下载结果 JSON 后跑 `python scripts/vcp_calc.py <文件> --code <代码>`（持仓检查加 `--cost`）。脚本输出：MA20、枢轴（前20日最高收盘）、距枢轴幅度、量比（近5日均量/前15日均量）、收缩判定（近60日三段振幅最新段<第一段）、状态分类（已突破 / VCP就绪 / 逼近 / 观察 / 破20日线）。
5. **输出清单**：每只候选给出收盘价、MA20、枢轴、距枢轴幅度、量比、止损位（近10日最低价）、止损距离、状态。参考仓位（单笔风险 2% ÷ 止损距离，上限 25%）仅对非出清区标的输出；「已突破」标的附突破后累计涨幅，>15% 标注追高风险。仅陈述规则计算结果，不作买卖结论。
6. **消息面三查前置（对「VCP就绪」与「已突破」标的强制执行）**：报告内逐只附三查清单——① 业绩兑现（用 `finance-report` 或 `financial-reports-fetcher` 查最新业绩/预告）；② 公告排雷（查减持、质押、立案等利空公告）；③ 催化阶段（板块催化处于发酵/主升/退潮哪一段）。任一不过关 → 该标的从候选清单降级并标注原因。
7. **突破标的加查**：状态为「已突破」且当日放量的，用 finance-hotlist 查是否上榜及席位性质，提示追入风险。

## 命令 2：持仓检查

用户给出代码列表时，逐只执行：

1. finance-data 取该股近 30 个交易日 K 线，下载 JSON 后跑 `vcp_calc.py --code <代码> --cost <成本> --board <main|20cm>`（用户未给成本时提醒补充；存量仓位必须带成本启用硬止损）。
2. 逐只给出动作：
   - **持有**：收盘在 MA20 之上且未破止损位
   - **止损离场**：收盘跌破止损位（技术位与 8%/12% 硬止损，先触发者）或跌破 20 日线
   - **止盈离场**：放量滞涨（价不涨量放大）加速离场
   - **加仓**：仅在盈利且突破后回踩企稳的金字塔加仓，绝不补仓摊平
3. **存量仓位纳管核查**：非信号仓位也要补技术止损 + 硬止损（成本 × 0.92 / 0.88），没有止损的持仓是体系最大漏洞。
4. 触发止损/止盈的标的，提示可用 finance-report 做深度归因。

## 命令 3：每周复盘

1. 用户提供本周交易台账（入场/出场日期、价格、盈亏、离场原因）；无台账先提醒建立。
2. 逐笔纪律打分：是否按规则买入（板块 RS 前 3、放量突破）？是否按规则止损/止盈（未死扛、未摊平）？
3. 绩效统计：胜率、平均盈/亏、盈亏比、累计收益、最大单笔回撤。
4. 更新主线板块：重跑两层 RS 方案，记录主线切换。
5. 输出「下周纪律改进点」，只保留数据支持的结论。触发离场的标的可用 finance-report 归因。

## 核心规则速览（为什么这么设）

- **只买板块 RS 前 3**：A 股是板块市，主线板块里选股胜率显著更高。
- **放量突破枢轴才买**：平台突破信号明确、可复盘；量能 ≥ 1.5 倍前 5 日均量，过滤无量假突破。
- **双保险止损**：技术位（跌破信号日低点/平台下沿）保形态逻辑，硬止损（主板 8%、20cm 股 12%）防黑天鹅；收盘价确认，不看盘中插针。
- **次日开盘跌破信号日最低价 → 不追入**：突破当天即失败，追入只会拿到「止损位高于买入价」的坏仓。
- **20 日线跟踪止盈**：让利润奔跑、吃主升段中段；放量滞涨作为加速离场信号。
- **单笔风险 1.5–2%，仓位 ≤25%**：仓位 = 风险 ÷ 止损距离；紧止损会算出超大仓位，一律 25% 截断。
- **单日回撤 3% 停开新仓、连亏 3 笔降档**：防连错失控，保护本金。
- **主线资格须 RS 为正、上证跌 >1.5% 全市场刹车**：v1.2 实盘补丁，过滤排名噪声和系统性杀跌日。

## 报告生成与存档

每次执行命令 1/2/3 后，必须生成详细 Markdown 报告：数据时点、全市场刹车判定、**板块代理 RS 排名表（rs_calc.py 完整输出：各股 20 日涨幅明细、中位数代理涨幅、一致性、5 日动量、代理 RS、硬门槛判定；样本不足 4 只的板块须标注）**、二线复核结论、主线板块、候选清单或持仓动作表（含止损位/参考仓位，出清区标的不得出现参考仓位）、**「VCP就绪/已突破」标的的消息面三查清单**、风险提示。

报告保存到工作目录：`VCP/reports/VCP扫描报告-YYYY-MM-DD.md`（持仓检查/周复盘同理改名），并交付给用户。
