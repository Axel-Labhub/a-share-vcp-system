# A股 VCP 交易体系 — 参数总表与决策依据

> 本文件是 `a-share-vcp-system` 技能的参考手册。参数由「扩散收敛法」对话结晶 + 纸面回测验证 + 首周实盘复盘逐步打磨而成。

## 参数总表

| 参数 | 值 | 说明 |
|------|-----|------|
| 持仓周期 | 2–8 周 | 日线级别信号，SEPA 原生节奏 |
| 市场过滤 | 板块 RS 前三 且 RS > 0 | 无主线板块则不开新仓 |
| 选股 | 板块内 VCP 形态龙头 | 收缩幅度递减、量能萎缩、逼近枢轴 |
| 买点 | 放量突破枢轴（量能 ≥ 前5日均量 1.5 倍，收盘站上） | 涨停买不进 → 次日不追，等回踩 |
| 止损 | 跌破枢轴/平台下沿 或 浮亏 8%（20cm 股 12%），先触发为准 | 收盘价确认，不看盘中插针 |
| 止盈 | 收盘跌破 20 日线 或 放量滞涨加速离场 | 吃主升段中段 |
| 单笔风险 | 1.5–2%（激进档） | 连亏 3 笔后降档至 1% |
| 单笔仓位上限 | ≤25%（硬性截断） | 回测发现紧止损会算出超大仓位，一律 25% 截断 |
| 最大持仓 | 5–6 只 | 单板块 ≤3 只 |
| 单日刹车 | 账户回撤 3% 停开新仓 | 防连错失控 |
| 加仓 | 仅盈利金字塔加仓 | 绝不补仓摊平 |
| 主线资格 | 20 日 RS 为正的板块才可标为主线 | 负 RS「主线」多为窗口噪声 |
| 全市场刹车 | 上证当日跌幅 >1.5% 停开一切新仓 | 系统性杀跌日不做买入 |
| 突破失败不追入 | 次日开盘跌破信号日最低价 → 放弃 | 避免止损位高于买入价的坏仓（见下方 bug 修复） |
| 存量仓位纳管 | 非信号仓位发现当日补技术止损+硬止损+仓位核查 | 无止损持仓是体系最大漏洞 |
| 消息面三查 | 入场前查业绩兑现 / 公告排雷 / 催化阶段，任一不过关降级 | 把自发核查固化为强制流程 |

## 决策依据摘要（为何是这个体系）

1. **体系定位**：完整实战系统，而非方法论研究。
2. **周期选中线波段**：A 股板块行情通常持续 1–3 个月，2–8 周吃主升段中段；无需全天盯盘；VCP 收缩在日线最典型。否决短线（T+1 隔夜风险）与中长线（15–20% 回撤考验）。
3. **市场过滤选行业相对强度**：SEPA 原生逻辑——只买相对大盘最强的板块。不叠加全局指数择时（记入延后口子）。
4. **选股选板块驱动**：A 股是板块市，主线板块内选股胜率更高。否决全市场扫描、基本面双轮、资金流驱动。
5. **买点选 VCP 突破**：平台突破信号明确、可复盘。A 股特有预案：突破当天可能涨停封死 → 次日不追高、等回踩。
6. **止损双保险**：技术位保形态逻辑，硬止损防黑天鹅；收盘价确认防插针扫损。20cm 股波动大，硬止损放宽至 12%。
7. **止盈 20 日线跟踪**：让利润奔跑、吃主升段中段；放量滞涨加速离场，板块退潮时少亏几个点。
8. **资金管理激进档**：单笔 2% × 止损 8% ≈ 仓位 25%，6 只满仓理论回撤 12%，连亏 3 笔 −6%。以承受 30%+ 回撤换取收益弹性。

## 延后口子（二期，占位不实现）

- 指数趋势开关：指数站上 200 日线且中期均线向上才允许开仓。
- 口袋支点买点：回调中放量上涨日低吸，VCP 突破前的抢先手。
- 基本面排雷清单：商誉、质押比例、减持计划等买入前排雷。
- 复盘自动化工具：交易记录、纪律打分、绩效统计自动化。

## 回测验证记录

### 原始回测（2026-08-11）

纸面回测（近 320 交易日，5 只样本股：兆易创新/宁德时代/比亚迪/赛力斯/中芯国际，前复权日线）：

| 指标 | 数值 |
|------|------|
| 交易笔数 | 22 |
| 胜率 | 54.5%（12 胜 / 10 负） |
| 平均盈利 / 平均亏损 | +13.92% / −5.21% |
| 盈亏比 | 2.67 |
| 单笔期望 | +5.22% |
| 累计账户贡献 | +72.95% |
| 最佳 / 最差 | +54.96% / −6.79% |

结论：8%/12% 硬止损与 20 日线止盈参数验证合理（硬止损实为尾部保险，多数止损由技术位在 −1%~−7% 提前触发）。暴露缺陷：止损距离过近时仓位公式算出超大仓位，已加 25% 上限修正。

### 独立复现验证（2026-08-19）

用 Python 独立重写回测逻辑 + 腾讯前复权真实数据重跑，**22 笔逐笔 100% 吻合**，全部统计指标一致。复现需注意两点：数据窗口须对齐回测日（`days=320` 实际返回 321 根），否则最早两笔被窗口前移切掉。

### Bug 修复（2026-08-20）

**账户贡献符号反转**：`acctRet = (riskPct / stopDist) × ret` 中，当次日开盘价跌破信号日最低价时，技术止损位高于买入价 → `stopDist` 为负 → 盈利被记成负贡献。唯一触发案例：兆易创新 2025-07-31（信号日最低价 122.56，次日开盘 120.25，`stopDist=−1.92%`，+0.11% 盈利错记 −0.11%）。

**修复**：入场前增加校验「次日开盘价必须高于信号日最低价，否则突破失败、不追入」，从根源保证 `stopDist` 恒为正。修复后 22 → 21 笔，仅剔除该笔假盈利，其余 21 笔逐笔不变，累计账户贡献 +72.95% → +73.06%。

## 实盘复盘记录（2026-08-11 至 08-19）

首周实运行验证结果：

- **验证有效**：锦浪信号全链路（板块RS+放量突破+追高线）正确触发；1.5 倍量能闸门拦下航发动力/中航西飞/埃斯顿三次无量假突破；追高线正确拦截天孚、光迅等已突破标的。
- **暴露缺陷与对应补丁**：
  1. 广合科技（非信号仓位）无预设止损，8-19 击穿硬止损清仓（−10.2%）→ 新增**存量仓位纳管**。
  2. 板块 RS 排名日间剧烈摆动（消费 +9.2%→−8.6%；机器人 −2.2% 负 RS 挂主线）→ 新增**主线资格须 RS 为正**。
  3. 8-19 系统性杀跌日扫描照常输出候选 → 新增**全市场刹车**（上证跌 >1.5% 停开新仓）。
  4. 消息面核查均为自发行为 → 固化为**入场前消息面三查**。
- **记录在案暂不修改**：回踩再入场规则（天孚案例样本不足）、候选状态→动作映射表。

## 数据源说明（当前平台环境，v1.5 适配）

本技能已从 ima.copilot 环境迁移至当前平台。原数据源（westock-data skill、mx-ds-mcp 的 `mx_index_block_finance_data` / `mx_ashare_finance_data`）在当前环境**不存在**，全部替换为平台已安装的技能矩阵：

| 数据需求 | 技能 | 说明 |
|---------|------|------|
| 个股 K 线/行情/技术指标 | `finance-data`（股票行情查询） | 异步模式：`submit_task` 提交自然语言查询 → `get_result` 凭 task_id 取结果。返回含 `technical_indicators`（MA/MACD/KDJ/RSI 现成）与 `sql_answer`（逐日明细）。**实测可用** |
| 板块权威 RS / 深度研判 | `finance-sector`（股票板块分析） | 重量级研报，用于二线复核、单板块研究、周复盘；**每日扫描不对全板块普调**（成本高） |
| 板块/个股资讯、轻量复核 | `finance-news`（股市资讯简报） | 板块涨跌报告、个股资讯，用于每日扫描的二线轻量复核与消息面三查 |
| 突破时资金席位核查 | `finance-hotlist`（龙虎榜解读） | 候选股放量突破当日/次日上龙虎榜时，核查机构/游资席位性质 |
| 持仓深度归因 | `finance-report`（股票深度分析） | 触发止损/止盈的持仓做深度归因，辅助复盘 |
| 财报/研报/公告排雷 | `financial-reports-fetcher`（财报与研报查询） | 入场前查业绩兑现、减持/质押公告 |
| 周线形态人工复核 | `technical-analyst`（K线图分析） | 用户提供周线图时叠加 VCP 位置解读 |

### 当前环境实测的关键限制（2026-08-21 至 08-23 验证）

1. **板块指数不可直查**：`finance-data` 查询「XX板块涨跌幅」会被误识别为个股（如「机器人板块」→ 个股机器人 300024.SZ）；查询同花顺行业指数返回空。**禁止重试 ≥2 次**（接口明确限制）。
2. **板块 ETF 行情也不可直查**：黄金ETF(518880)、半导体ETF(512480) 实测均返回空——行情接口数据库只覆盖 A 股个股。**代表股代理是板块强度的唯一可行路径**。
3. **指数行情滞后一个交易日**：上证指数逐日序列实测最新仅到前一收盘日；个股 K 线则是最新的（含当日）。全市场刹车判定须用个股口径或资讯补齐当日指数涨跌幅。
4. **结果数据在远程 JSON**：`get_result` 返回体里 `result_json_path` 是完整数据文件，需下载到本地解析（`sql_answer` 数组，按 `trade_date` 降序，须反转升序后再计算）。
5. **确定性计算双脚本**：板块代理 RS 用 `scripts/rs_calc.py`（中位数 + 一致性 + 5 日动量，三条硬门槛自动判定）；个股 VCP 指标用 `scripts/vcp_calc.py`（MA20/枢轴/量比/收缩/止损位/参考仓位，出清区不输出仓位、已突破标注追高）。禁止手算。
