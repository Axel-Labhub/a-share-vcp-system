## 这是什么

一句话：**只做相对强度（RS）最强板块里的 VCP 形态龙头，放量突破买，破位止损、破 20 日线走。**

它是米内尔维尼 **SEPA / VCP** 趋势思想在 A 股的本土化落地——中线波段（2–8 周）、板块驱动选股、技术位+硬性双保险止损、20 日线跟踪止盈。

但它的特别之处不在"又一套指标"，而在**它是怎么被造出来的**：

```
一个想法 ──扩散收敛法──▶ 八条决策 ──结晶──▶ 手稿 ──封装──▶ Agent Skill
                                                            │
            实盘信号 ◀──运行── 回测修参 ◀──验证── 纸面回测 ◀─┘
```

全程由 AI 作为"思维合伙人"共建，每一步的**依据、被否决的方案、踩过的坑**都留了档。你拿到的不只是一个工具，而是一份"如何用 AI 造工具"的完整样本。

## 成绩单

近 15 个月、5 只样本股、22 笔交易的纸面回测：

| 指标 | 数值 | 怎么读 |
|------|------|--------|
| **胜率** | 54.5% | 靠的不是高胜率 |
| **盈亏比** | 2.67 | 赚的时候是亏的 2.67 倍 |
| **单笔期望** | +5.22% | 正期望 = 长期可做的前提 |
| **累计账户贡献** | +72.95% | 单笔风险 2% 仓位模型下 |
| **最大单笔** | +61.97% | 让利润奔跑的样子 |

> 本质是**截断亏损、让利润奔跑**：多数小亏 + 少数大赚。这不是"稳赚"，是一套**有正期望、可执行、可复盘**的规则。

技术面、板块面、消息面三线共振才出手——这是体系的纪律，不是运气。

## 核心规则速览

| 环节 | 规则 |
|------|------|
| 持仓周期 | 2–8 周（日线信号） |
| 市场过滤 | 只做板块相对强度前三 |
| 买点 | 放量突破 20 日枢轴（量 ≥ 前 5 日均量 1.5 倍，收盘站上） |
| 止损 | 跌破枢轴/平台下沿 或 浮亏 8%（20cm 股 12%），收盘确认 |
| 止盈 | 收盘跌破 20 日线，或放量滞涨加速离场 |
| 资金管理 | 单笔风险 1.5–2%，单笔仓位 ≤25%，最多 5–6 只，单板块 ≤3 只 |
| 风控刹车 | 单日回撤 3% 停开新仓；连亏 3 笔降档运行 |

完整决策依据、被否决的方案、延后口子 → [`skills/a-share-vcp-system/rules.md`](skills/a-share-vcp-system/rules.md)

## 30 秒安装

**方式一（推荐）**：用支持 `.skill` 的客户端（如千问办公）打开 [`dist/a-share-vcp-system.skill`](dist/a-share-vcp-system.skill)，点"保存技能"。

**方式二（通用）**：把 `skills/a-share-vcp-system/` 复制到你的技能目录：

```bash
cp -r skills/a-share-vcp-system ~/.qwenworkcn/skills/   # 千问办公
cp -r skills/a-share-vcp-system ~/.claude/skills/       # Claude Code
```

装好后，对 AI 说：

| 你说 | 它做 |
|------|------|
| "执行每日选股扫描" | 板块 RS 排名 → 主线板块 VCP 候选清单 |
| "检查我的持仓 603986, 300763" | 逐只给出持有/止损/止盈/加仓动作 |
| "执行每周复盘" | 纪律打分 + 绩效统计 + 更新主线板块 |
| "展示交易体系参数总表" | 全部参数与决策依据 |

- 想找"稳赚代码"的人——没有这种东西，正期望 ≠ 不亏损
