# A股 VCP 趋势交易体系（a-share-vcp-system）

一个从"模糊想法"到"可运行 Agent Skill"的完整案例：用**扩散收敛法**与 AI 共建了一套 A 股中线波段 VCP 趋势交易体系（米内尔维尼 SEPA 的 A 股本土化），并通过纸面回测验证参数，最终封装成任何 SKILL.md 兼容智能体都能安装执行的技能包。

> 本项目是交易方法论与 Agent Skill 工程的双重实践，仅供学习研究，不构成投资建议。

## 体系一句话

**只做相对强度（RS）最强板块里的 VCP 形态龙头，放量突破买，破位止损、破 20 日线走。**

完整链路：市场过滤（板块 RS）→ 选股（板块内 VCP 龙头）→ 买点（放量突破枢轴）→ 止损（技术位 + 硬性双保险）→ 止盈（20 日线跟踪）→ 资金管理（激进档）→ 每周复盘。

## 核心参数速览

| 参数 | 值 |
|------|-----|
| 持仓周期 | 2–8 周（日线信号） |
| 市场过滤 | 板块相对强度前三 |
| 买点 | 放量突破 20 日枢轴（量 ≥ 前5日均量 1.5 倍） |
| 止损 | 跌破枢轴/平台下沿 或 浮亏 8%（20cm 股 12%），收盘确认 |
| 止盈 | 收盘跌破 20 日线，或放量滞涨加速离场 |
| 资金管理 | 单笔风险 1.5–2%，单笔仓位 ≤25%，最多 5–6 只，单板块 ≤3 只 |
| 刹车 | 单日回撤 3% 停开新仓；连亏 3 笔降档 |

完整决策依据、被否决方案与延后口子见 [`skills/a-share-vcp-system/rules.md`](skills/a-share-vcp-system/rules.md)。

## 安装与使用

**方式一（推荐）**：在支持 `.skill` 格式的客户端（如千问办公）中打开 `dist/a-share-vcp-system.skill`，点击"保存技能"即可。

**方式二（通用）**：将 `skills/a-share-vcp-system/` 目录复制到你的技能目录，例如：

```bash
cp -r skills/a-share-vcp-system ~/.qwenworkcn/skills/   # 千问办公
cp -r skills/a-share-vcp-system ~/.claude/skills/       # Claude Code
```

装好后对 Agent 说：

- "执行每日选股扫描" — 板块 RS 排名 + 主线板块 VCP 候选清单
- "检查我的持仓 603986, 300763" — 逐只对照规则给出持有/止损/止盈/加仓动作
- "执行每周复盘" — 纪律打分 + 绩效统计 + 主线板块更新
- "展示交易体系参数总表" — 全部参数与决策依据

## 回测摘要（2026-08-11）

近 15 个月、5 只样本股、22 笔交易：**胜率 54.5%，盈亏比 2.67，单笔期望 +5.22%**。8%/12% 硬止损验证为"尾部保险"（多数止损由技术位提前触发），20 日线止盈成功拿住全部大趋势。

回测也抓出一个真实缺陷：止损距离过近时仓位公式会算出超大仓位——已修正为**单笔仓位 25% 硬上限**。局限（样本小、未启用板块过滤、未计成本）详见回测报告。

## 项目缘起

本项目完整演示了一条"想法 → 技能"的流水线：

1. **扩散收敛**（[diverge-converge](https://github.com/linshidream/skill-hub)，来自 [Skill Hub](https://github.com/linshidream/skill-hub)）：八轮问答锁定八条决策，结晶为手稿；
2. **封装执行层**：手稿 → SKILL.md 技能包，规则固化为可重复执行的协议；
3. **回测验证**：纸面回测验证参数、发现缺陷、补丁回写技能；
4. **实战运行**：首个信号于 2026-08-11 由每日扫描产出（锦浪科技 300763 放量突破），技术面与消息面交叉验证通过。
