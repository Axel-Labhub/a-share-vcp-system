## 这是什么

一句话：**只做相对强度（RS）最强板块里的 VCP 形态龙头，放量突破买，破位止损、破 20 日线走。**

它是米内尔维尼（Mark Minervini）**SEPA / VCP** 趋势思想在 A 股的本土化落地：

| 维度 | 设计 |
|------|------|
| 周期 | 中线波段 2–8 周（日线信号，SEPA 原生节奏） |
| 选股 | 板块驱动——先锁定主线板块，再在板块内找 VCP 形态龙头 |
| 买点 | 放量突破 20 日枢轴（量能 ≥ 前 5 日均量 1.5 倍，收盘站上） |
| 风控 | 技术位 + 硬性双保险止损（主板 8% / 20cm 股 12%），收盘确认 |
| 止盈 | 20 日线跟踪止盈 + 放量滞涨加速离场 |
| 仓位 | 单笔风险 1.5–2%，仓位 = 风险 ÷ 止损距离，硬性上限 25% |

但它的特别之处不在"又一套指标"，而在**它是怎么被造出来的**：

```
一个想法 ──扩散收敛法──▶ 八条决策 ──结晶──▶ 手稿 ──封装──▶ Agent Skill
                                                            │
            实盘信号 ◀──运行── 回测修参 ◀──验证── 纸面回测 ◀─┘
                │
                ▼
        首周实盘复盘 ──▶ 四条补丁 ──▶ v1.2
                │
                ▼
        两次完整扫描复盘 ──▶ 准确性改造 ──▶ v1.5
```

全程由 AI 作为"思维合伙人"共建，每一步的**依据、被否决的方案、踩过的坑**都留了档。你拿到的不只是一个工具，而是一份"如何用 AI 造工具"的完整样本。

## 成绩单：纸面回测

> 数据窗口：近 320 个交易日（约 15 个月）· 数据源：腾讯前复权日线 · 样本：兆易创新 / 宁德时代 / 比亚迪 / 赛力斯 / 中芯国际

### 总体统计

| 平均盈利 | +13.92% | 让利润奔跑 |
| 平均亏损 | −5.21% | 截断亏损 |
| **盈亏比** | 2.67 | 赚的时候是亏的 2.67 倍 |

### 收益结构的本质

这套体系的盈利不靠高胜率，而靠**右尾肥厚**：亏损被压缩在平均 −5.21%，而盈利端能跑出 +54.96% 的单笔。代价是你要接受近一半的交易是亏损的，且多数亏损发生在持仓 1–3 天的快速止损上。心理上必须认同"亏小钱是成本，不是失败"。

### 三个关键参数的验证结论

| 参数 | 验证结果 |
|------|---------|
| 8% 硬止损（主板） | **尾部保险**——绝大多数止损在 −1%~−7% 由技术位提前触发，硬止损只在极端情况兜底 |
| 12% 硬止损（20cm） | **有效**——中芯国际一笔触及 −12.25% 恰被兜住；分板设置被数据支持 |
| 20 日线跟踪止盈 | **利润引擎**——全部 13 笔 MA20 退出包含所有大趋势（+54.96%、+28.43%、+19.32%…） |

> 本质是**截断亏损、让利润奔跑**：多数小亏 + 少数大赚。这不是"稳赚"，是一套**有正期望、可执行、可复盘**的规则。

| 实盘事故 | 补丁 |
|---------|------|

> 每一条补丁都来自真实亏损或真实风险暴露，不是拍脑袋加的。

| 选股 | 板块内 VCP 形态龙头 | 收缩幅度递减、量能萎缩、逼近枢轴 |

| 止盈 | 收盘跌破 20 日线 或 放量滞涨加速离场 | 吃主升段中段 |
| 单笔风险 | 1.5–2%（激进档） | 连亏 3 笔后降档至 1% |
| 单笔仓位上限 | ≤25%（硬性截断） | 紧止损会算出超大仓位，一律截断 |
| 最大持仓 | 5–6 只 | 单板块 ≤3 只 |
| 单日刹车 | 账户回撤 3% 停开新仓 | 防连错失控 |
| 加仓 | 仅盈利金字塔加仓 | 绝不补仓摊平 |
| 主线资格 | 20 日 RS 为正的板块才可标为主线 | 负 RS「主线」多为窗口噪声 |
| 全市场刹车 | 上证当日跌幅 >1.5% 停开一切新仓 | 系统性杀跌日不做买入 |

| 存量仓位纳管 | 非信号仓位发现当日补技术止损+硬止损+仓位核查 | 无止损持仓是体系最大漏洞 |

## v1.5 两层 RS 方案与确定性硬门槛

### 问题：板块指数行情无法直查

当前数据环境下，板块指数 / 板块 ETF 行情均不可查询（实测验证）。唯一可行路径：**用代表股代理板块强度**。

但简单的「龙头股均值」会被单只妖股绑架——实测案例：

> 医药板块代理涨幅 +7.42%，全靠药明康德一只（+30.3%），恒瑞实为 −10.7%。
> 如果按均值法，医药会被判为主线——这是错误的。

### 解法：三条确定性硬门槛

v1.5 引入 `scripts/rs_calc.py`，对每个板块的代表股（≥4 只）批量计算，**全部自动判定，禁止人工覆盖**：

| 门槛 | 规则 | 拦截什么 |
|------|------|---------|
| ① 一致性 ≥ 50% | 代表股中 20 日涨幅为正的比例过半 | 单股绑架（真主线是群体上涨） |
| ② 代理 RS > 0 | 代理涨幅（**中位数**）超过基准指数 | 负 RS 噪声 |
| ③ 5 日动量中位数 ≥ −3% | 短期资金未撤离 | 正在退潮的假主线 |

三条全过 → **主线候选**；任一不过 → 降级。

### 回放验证（2026-08-21 数据）

| 板块 | 一致性 | 代理RS | 5日动量 | 判定 |
|------|--------|--------|---------|------|
| **贵金属** | 100% | +30.66% | +18.12% | ✅ 主线候选 |
| 医药生物 | 50% | +9.11% | −3.5% | ❌ 降级（动量背离） |
| 机器人 | 75% | +6.61% | −3.47% | ❌ 降级（动量背离） |
| 光伏 | 50% | +1.15% | −3.0% | ❌ 降级（动量背离） |
| 半导体 | 0% | −11.19% | −3.28% | ❌ 降级（一致性+负RS+动量） |

> 医药/机器人/光伏三个被单股绑架的假主线**全部被自动拦截**，无需人工解读简报。

## 工程严谨性

### 独立复现验证（2026-08-19）

用 Python **独立重写**回测逻辑 + 腾讯前复权真实数据重跑，**22 笔逐笔 100% 吻合**，全部统计指标一致。

### Bug 修复（2026-08-20）

**账户贡献符号反转**：当次日开盘价跌破信号日最低价时，技术止损位高于买入价 → 止损距离为负 → 盈利被记成负贡献。

**修复**：入场前增加校验「次日开盘价必须高于信号日最低价，否则突破失败、不追入」。修复后 22 → 21 笔，累计贡献 +72.95% → +73.06%。

### 确定性计算，禁止手算

所有指标由脚本计算，杜绝人为误差：

| 脚本 | 职责 |
|------|------|
| `scripts/rs_calc.py` | 板块代理 RS：中位数 + 一致性 + 5 日动量 + 三条硬门槛自动判定 |
| `scripts/vcp_calc.py` | 个股 VCP：MA20 / 枢轴 / 量比 / 收缩 / 止损位 / 参考仓位 / 状态分类 |

## 局限与诚实声明

这套体系有明确的边界，我们选择全部公开：

| 局限 | 说明 |
|------|------|
| 样本极小 | 22 笔、5 只手工挑选的大盘股，统计意义有限。严肃验证需 100+ 笔 |
| 选择偏差 | 样本本身就是体系擅长捕捉的强趋势股，存在循环论证 |
| 未启用板块过滤 | 回测只验证了个股买卖规则，板块 RS 过滤未参与（等于测了引擎没测方向盘） |
| 未计成本 | 未含佣金、印花税（卖出 0.1%）、滑点，实际收益会打折扣 |
| 贡献集中 | 很大一块正收益来自兆易创新一笔 +54.96%，样本集中度高 |
| +73% 非复利 | 是账户贡献累加，非真实组合收益（未建模并发持仓与资金约束） |
| 代理 RS 有失真风险 | 代表股近似板块强度仍可能失真，需二线复核兜底 |

> 我们选择公开这些，因为**正期望 ≠ 不亏损**。一套诚实标注局限的系统，比一套吹嘘胜率的系统更值得信赖。
