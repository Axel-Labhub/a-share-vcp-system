# A股中线波段VCP交易体系 手稿

> 生成方式：由「扩散收敛法」技能在对话闭合后结晶生成。本手稿忠实记录了 2026-08-11 对话中共同探索出的全部决策、依据、被否决项与延后口子，可被任何智能体或工程师直接接手实施。

## 背景与目标

- **背景**：用户是 A 股市场参与者，长期关注个股走势与资金动向（如兆易创新 603986），对米内尔维尼 SEPA/VCP 趋势交易体系及其 A 股本土化感兴趣。表层诉求是"构建一套交易体系"。
- **真正的问题**：建立一套**能理解、愿意长期执行、且适配 A 股生态的完整决策规则系统**——从选股、买点、卖出到资金管理，可直接实盘执行。不是方法论研究，也不是学习框架。
- **目标与验收**：MVP = 一份完整可执行的规则手册，覆盖 市场过滤 → 选股 → 买点 → 止损 → 止盈 → 资金管理 → 复盘 的闭环，可进入纸面验证与小仓实盘阶段。

## 关键决策汇总

1. **体系定位**：完整实战系统（选股→买点→卖出→仓位→风控全流程，可实盘执行）
2. **交易周期**：中线波段，持仓 2–8 周，日线级别信号
3. **市场过滤**：行业相对强度过滤（只参与 RS 最强板块）
4. **选股引擎**：板块驱动选股（板块 RS + 资金流 → 板块内 VCP 形态龙头）
5. **买点信号**：VCP 突破买点（波动收缩至极致 + 放量突破枢轴），附涨停买不进预案
6. **止损规则**：技术位 + 硬性双保险（跌破枢轴/平台下沿；8% 硬止损，20cm 股 12%；收盘价确认）
7. **止盈规则**：20 日线跟踪止盈（收盘跌破卖出）+ 放量滞涨加速离场
8. **资金管理**：激进档（单笔风险 1.5–2%，最多 5–6 只，单板块 ≤3 只，仅盈利金字塔加仓）

## 各专题深入

### 1. 体系定位

- **选择**：完整实战系统。用户已有明确的 SEPA/VCP 方向和实践意图，不需要停留在方法论研究或学习框架阶段。
- **被否决**：本土化方法论研究（产出研究结论而非系统，不满足实战意图）；学习验证框架（MVP 优先原则下仍要完整闭环）。

### 2. 交易周期

- **选择**：中线波段（2–8 周，日线）。SEPA/VCP 原生节奏；A 股板块行情持续 1–3 个月，2–8 周持仓能吃到主升段中段；无需全天盯盘；VCP 收缩形态在日线级别最典型。
- **被否决**：短线波段（3–10 天）——T+1 隔夜风险大、需每日盯盘、手续费磨损、VCP 在短周期不成立；中长线趋势（1–6 个月）——需容忍 15–20% 回撤，A 股波动下持盈考验大。

### 3. 市场过滤

- **选择**：行业相对强度过滤——只买相对大盘 RS 最强的行业/板块中的股票，SEPA 原生逻辑。
- **被否决**：指数趋势开关（用户未选择；虽为更稳妥的全局安全网，但尊重用户"靠板块和个股质量取胜"的立场，记入延后口子）；市场宽度过滤（上涨家数占比等，数据维护成本高，MVP 过重）。
- **风险提示（记录在案）**：不做全局择时，指数级下跌时体系仍会亏损——这是用户明确接受的代价，延后口子中保留指数趋势开关以备二期叠加。

### 4. 选股引擎

- **选择**：板块驱动选股。先锁定 RS 最强板块（题材 + 资金流 + 板块 RS），再从板块内筛选 VCP/突破形态龙头。与已锁定的行业过滤天然同构，执行链路最短。
- **被否决**：全市场 RS+形态扫描（与行业过滤脱节，两套逻辑打架，噪音多）；基本面+技术双轮（SEPA 原版，但 A 股财务数据季度披露、可比性差，踩雷风险高）；资金流驱动（主力净流入/龙虎榜/北向，数据真实性和时效难验证，易做成追涨杀跌）。
- **延后口子**：基本面排雷清单（买入前的财务排雷，如商誉、质押、减持，不参与主筛选）。

### 5. 买点信号

- **选择**：VCP 突破买点——波动连续收缩（每次收缩幅度递减）至极致后，放量突破枢轴点买入。
- **A 股特有预案（强制规则）**：突破当天若直接涨停封死买不进 → 次日高开不追，等待回踩企稳再介入。
- **被否决**：口袋支点（回调中放量上涨日买入，识别难、执行门槛高，记入延后口子）；回踩均线买点（强势股常不回头，容易踏空）；52 周新高买点（高位追入 + 涨跌停放大波动，风险最高）。

### 6. 止损规则

- **选择**：技术位 + 硬性双保险。跌破 VCP 枢轴/平台下沿即卖出；同时设硬止损（主板约 8%，创业板/科创板 20cm 股约 12%），先触发者为准。
- **执行细节（强制）**：止损用**收盘价确认**，避免盘中插针扫损。
- **被否决**：纯百分比硬止损（无视形态，好票被震出）；纯技术位止损（无硬约束，极端行情亏损失控）；波动率止损 ATR（参数化复杂，MVP 过重）。

### 7. 止盈规则

- **选择**：均线跟踪止盈——持有期间收盘跌破 20 日线卖出；同时以"放量滞涨"（长上影、天量收阴）作为加速离场的辅助触发条件。
- **被否决**：固定目标止盈（+20% 分批，截断大趋势，收益天花板低）；纯信号驱动卖出（主观成分大，规则难完全量化）；时间止损（强势股启动慢，易卖在启动前）。

### 8. 资金管理

- **选择**：激进档。单笔风险 1.5–2%（R）；最多同时持有 5–6 只；单板块集中度 ≤3 只；仅盈利后金字塔加仓，绝不补仓摊平。
- **强制刹车（无论档位）**：单日账户回撤 3% 即停止开新仓；连续 3 笔止损暂停开仓 1 周并降档运行。
- **风险数字（明示）**：单笔 2% 风险 × 8% 止损距离 ≈ 单笔仓位 25%；6 只满仓时账户理论回撤可达 12%；连续 3 笔止损即 −6%。激进档以承受 30%+ 回撤换取收益弹性。
- **被否决**：标准档（单笔 1%、5 只、单板块 ≤2 只，回撤可控但弹性低——用户主动选择激进）；保守档（0.5–0.75%、3 只，曲线平滑优先——不匹配用户风格）。

## 实施步骤

1. **建立数据源**：板块 RS 排名数据 + 个股行情（可用公开行情接口，如腾讯行情 qt.gtimg.cn，GBK 编码，`curl https://qt.gtimg.cn/q=sh603986` 可获取现价/涨跌幅/成交额等字段）。
2. **建立板块强度清单**：按板块 RS（板块指数相对大盘的相对强度）+ 资金流入，每周更新排名，锁定当前主线板块。
3. **建立候选池扫描**：主线板块内扫描 VCP 形态（波动收缩幅度递减、接近枢轴、量能萎缩），每日更新候选清单。
4. **纸面验证**：用最近 3–6 个月的行情按规则模拟交易 2–4 周，验证 8%/12% 止损、20 日线止盈、仓位公式的参数合理性。
5. **小仓实盘**：以总资金 1–2% 起步实盘，完整执行信号，不做任何临时判断。
6. **每周复盘**：对照纪律清单逐条打分，记录每笔交易的买因/卖因/情绪偏差；连亏 3 笔自动降档运行。

## 被否决项与延后口子

### 被否决的方案及理由

- 短线波段（3–10 天）：T+1 隔夜风险大、需全天盯盘、VCP 短周期不成立。
- 中长线趋势（1–6 个月）：需容忍 15–20% 回撤，A 股波动下持盈考验大。
- 市场宽度过滤：数据维护成本高，MVP 过重。
- 全市场 RS 扫描：与行业过滤脱节，逻辑打架。
- 基本面+技术双轮：A 股财务数据季度披露、可比性差，踩雷风险高。
- 资金流驱动选股：数据真实性和时效难验证，易追涨杀跌。
- 口袋支点：信号识别难，执行门槛高。
- 回踩均线买点：强势股常不回头，容易踏空。
- 52 周新高买点：高位追入 + 涨跌停放大波动，风险最高。
- 纯百分比止损：无视形态，好票被震出。
- 纯技术位止损：无硬约束，极端行情亏损失控。
- ATR 止损：参数化复杂，MVP 过重。
- 固定目标止盈：截断大趋势，长期收益天花板低。
- 纯信号卖出：主观成分大，难量化。
- 时间止损：强势股启动慢，易卖在启动前。
- 标准档/保守档资金管理：用户主动选择激进档。

### 延后到下一期的口子

- 指数趋势开关：指数级下跌时的安全网；实现方式为"指数站上 200 日线且中期均线向上才允许开仓"，二期决定是否叠加。
- 口袋支点买点：与回踩买点同属"低吸"分支，作为 VCP 突破的抢先手增强。
- 基本面排雷清单：买入前财务排雷（商誉、质押比例、减持计划），不参与主筛选。
- 复盘自动化工具：交易记录、纪律打分、绩效统计的自动化，降低执行负担。

## 待核对事项

- 板块 RS 的准确计算口径与可靠数据源（当前用公开行情接口自行计算，具体字段与频率待核对）。
- VCP 形态扫描的实现方式（人工看图 vs 脚本扫描），MVP 可先人工，二期自动化。
- 8%/12% 止损参数与 20 日线止盈在 A 股的实证回测表现（纸面验证阶段核对）。
- 激进档（R 1.5–2%）在实盘中的心理承受能力验证（小仓实盘阶段核对）。
